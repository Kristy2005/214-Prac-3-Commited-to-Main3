Detailed Description

Concrete Leaf component representing a performance stage.

GoF Role: ConcreteObserver (Observer Pattern) / Leaf (Composite Pattern). Represents active music/performance stages across festival zones. Responds to operational, capacity, and safety notifications (e.g., PAUSE, RESUME, WEATHER_ALERT, EVACUATE).
