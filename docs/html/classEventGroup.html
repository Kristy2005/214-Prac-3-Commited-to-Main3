Detailed Description

Composite class representing a festival zone/group containing multiple components.

GoF Roles: Composite (Composite Pattern) / Subject & ConcreteObserver (Observer Pattern). Acts as both a container for child EventComponents and an intermediate router that receives notifications from above and cascades them to registered observers below (Task 3.4).
