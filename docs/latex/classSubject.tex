\doxysubsection{Detailed Description}
Abstract \mbox{\hyperlink{classSubject}{Subject}} base class managing observer registrations and notifications. 

GoF Role\+: \mbox{\hyperlink{classSubject}{Subject}}. Ownership policy\+: Stores non-\/owning pointers in {\ttfamily observers}. Does not delete observers upon detachment or destruction, allowing observers to exist independently within the Composite structure.
