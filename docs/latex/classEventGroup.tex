\doxysubsection{Detailed Description}
Composite class representing a festival zone/group containing multiple components. 

GoF Roles\+: Composite (Composite Pattern) / \mbox{\hyperlink{classSubject}{Subject}} \& Concrete\+Observer (\mbox{\hyperlink{classObserver}{Observer}} Pattern). Acts as both a container for child Event\+Components and an intermediate router that receives notifications from above and cascades them to registered observers below (Task 3.\+4).
