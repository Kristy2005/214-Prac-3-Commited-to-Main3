\doxysubsection{Detailed Description}
Concrete Leaf component representing a performance stage. 

GoF Role\+: Concrete\+Observer (\mbox{\hyperlink{classObserver}{Observer}} Pattern) / Leaf (Composite Pattern). Represents active music/performance stages across festival zones. Responds to operational, capacity, and safety notifications (e.\+g., PAUSE, RESUME, WEATHER\+\_\+\+ALERT, EVACUATE).
