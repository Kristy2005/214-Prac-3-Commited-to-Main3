\doxysubsection{Detailed Description}
Abstract \mbox{\hyperlink{classObserver}{Observer}} interface in the \mbox{\hyperlink{classObserver}{Observer}} design pattern. 

GoF Role\+: \mbox{\hyperlink{classObserver}{Observer}}. Defines the update interface for objects that receive notifications from Subjects. Observers are non-\/owning references stored by Subjects and must detach prior to destruction.
